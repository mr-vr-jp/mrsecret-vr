PCVR Setup

PCVR版のセットアップ

SteamVRのインストール

  1. PCでSteamを起動
  2. 画面上部のストアを開く
  3. SteamVRを検索
  4. 緑のボタン（ライブラリに追加またはプレイ）を選択し、インストールを完了

インストール後は、Steamのライブラリの「ツール」から起動できます。

ゲームファイルの配置

  1. ダウンロードしたゲームファイルを展開
  2. 展開したフォルダMRsecretVR_PCVRを、日本語（全角文字）が含まれないフォルダに置く

全角文字が含まれるとゲーム内での入力が効かなくなる場合があります。

VRヘッドセットの接続とSteamVRの起動

使っているヘッドセットを選んでください。接続が完了すると、SteamVRのホーム画面がヘッドセットに表示されます。

  1. VRヘッドセットをPCに接続
  2. SteamVRを起動
  1. PCにMeta Horizon Link アプリ（旧 Meta Quest Link）をインストール
  2. Questのナビゲーターからクイックコントロール→Linkを開く
  3. PCを選んで起動Air Link（無線）の場合はAir Linkを使用をオンにしてペアリングが必要です
  4. Linkのホーム画面からSteam VRを選択して起動
  1. ヘッドセットにVirtual Desktopアプリをインストール（別途購入必要。QuestはMeta Horizon Store、PICOはPICO Storeで購入）
  2. PCにVirtual Desktopストリーマーをインストールし、ACCOUNTSにヘッドセット（Meta／PICO）のアカウントのユーザー名を入力してSave
  3. ヘッドセットでVirtual Desktopを起動し、PCと接続接続が成功するとヘッドセット内にPC画面が表示されます
  4. 左メニューからLaunch SteamVRを選択

ゲームの起動

  1. 配置したMRsecretVR_PCVRフォルダを開く
  2. MRsecretVR.exeをダブルクリック
  3. ゲームが起動し、VRヘッドセットにゲーム画面が表示されます

Quest Setup

Quest単体版のセットアップ

開発者モードの有効化

  1. Meta Quest for Developersで組織を登録下の「組織登録の手順」を参照
  2. スマホのBluetoothをオンにして、Meta Horizonアプリ（旧 Meta Questアプリ）を起動
  3. 三本線アイコンのメニューからデバイスを選択
  4. お使いのQuestを選択（「接続済み」と表示されていることを確認）
  5. ヘッドセットの設定→開発者モードをオン
  6. Quest本体を再起動
組織登録の手順
  1. Meta Quest for Developersにアクセスし、Meta Questのアカウントでログイン
  2. 本人確認のため、クレジットカード情報の登録（請求は発生しません）または二段階認証を設定
  3. 組織名を登録非公式アプリをプレイするだけの場合は任意の名前で問題ありません

ADBドライバーのインストール

  1. Meta Quest開発者センターでDownloadをクリック
  2. 「I have read and agree to the terms of the license .」にチェックを入れ、Downloadで保存
  3. zipファイルを解凍
  4. android_winusb.infを右クリックしインストールを選択
  5. 「この操作を正しく終了しました」と表示されたらOK

SideQuestのインストール

  1. SideQuest公式サイトの「Advanced Installer」からDOWNLOAD FOR WINDOWSをクリック
  2. ダウンロードしたファイルを実行してインストール

QuestとPCの接続

  1. QuestとPCをUSBケーブルで接続
  2. Quest内で「USBデバッグを許可しますか？」→許可する次回から省くには「このコンピューターを常に許可」にチェック
  3. ホームメニュー下部のベルアイコンのお知らせ→USBが検出されましたを選択
  4. 「接続したデバイスにファイルへのアクセスを許可しますか？」→許可する

ゲームのインストール

  1. SideQuestを起動し、Questが認識されていることを確認No device connectedと表示される場合は接続できていません。PCとの接続を確認してください
  2. 上部のSideloadを開く
  3. MRsecretVR.apkを枠の中へドロップ（またはクリックして選択）
  4. HistoryにCompletedと表示されたら完了

ゲームの起動

  1. Metaボタンでメニューを開き、下部中央のライブラリを選択
  2. ライブラリ左端の三（メニュー）を選択
  3. 提供元不明を選択
  4. MRsecretVRを選択して起動

左端のメニューのアイコンは小さくて押しづらいことがあります。Quest本体の画面の作りによるものです。ゆっくり動かして、「メニュー」と表示されたら押してください。

※Questのバージョンによって「提供元不明」を開く手順が若干異なります。表示されない場合は開発者モードが有効になっていない可能性があるので、Quest本体を再起動してください。

開発者モードの有効化

A方式の開発者モードの有効化と同じ手順で設定してください。

APKファイルの準備

  1. QuestのブラウザからDLSiteにアクセスし、ログインしてゲームをダウンロード
  2. ファイルアプリを開き、ダウンロードしたzipファイルの…→抽出を選択

展開に失敗する場合は方法2をお試しください。圧縮したままのAPKはインストールできません。

  1. PCでダウンロードしたゲームファイルを展開
  2. QuestとPCをUSB接続
  3. Quest内でファイルアクセスを許可を選択
  4. PCからQuestのDownloadフォルダにMRsecretVR.apkをコピー

APKのインストール

  1. ファイルアプリでMRsecretVR.apkを探す
  2. APKの…→使用するアプリを選択→パッケージインストーラ
  3. インストール→完了

ゲームの起動

  1. Metaボタンでメニューを開き、下部中央のライブラリを選択
  2. ライブラリ左端の三（メニュー）を選択
  3. 提供元不明を選択
  4. MRsecretVRを選択して起動

左端のメニューのアイコンは小さくて押しづらいことがあります。Quest本体の画面の作りによるものです。ゆっくり動かして、「メニュー」と表示されたら押してください。

※Questのバージョンによって「提供元不明」を開く手順が若干異なります。表示されない場合は開発者モードが有効になっていない可能性があるので、Quest本体を再起動してください。

Update

アップデート手順

PC版、Quest版ともにセーブデータは引き継がれます。

PCVR版

  1. ダウンロードしたファイルを展開
  2. 新バージョンのMRsecretVR.exeを実行
ゲーム開始画面でメニューが選択できない場合
  • ゲームフォルダを別の場所に移動してみてください（例: Downloads → Desktop）
  • または、フォルダ名を最初に起動した時の名前に戻してみてください（例: MRsecretVR_ver1.0.1 → MRsecretVR_ver1.0）

Quest単体版

  1. 新バージョンのMRsecretVR.apkを用意
  2. 通常のインストール手順と同様にSideQuestでインストール自動的に上書きインストールされます

SideQuestでインストールできない場合は、B. Quest本体のファイルアプリの手順で実施してください。

アップデートが完了したら、新機能や改善された体験をお楽しみください！
