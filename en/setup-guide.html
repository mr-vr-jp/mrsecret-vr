01

PCVR Setup

Setting Up the PCVR Version

Install SteamVR

  1. Launch Steam on your PC
  2. Open Store at the top
  3. Search for SteamVR
  4. Select the green button (Add to Library or Play) and finish installing

Once installed, launch it from "Tools" in your Steam Library.

Place the Game Files

  1. Extract the downloaded game files
  2. Place the extracted MRsecretVR_PCVR folder where you want to keep the game

Connect Your Headset and Start SteamVR

Choose the headset you use. Once connected, the SteamVR home appears in your headset.

  1. Connect the VR headset to your PC
  2. Start SteamVR
  1. Install the Meta Horizon Link app (formerly Meta Quest Link) on your PC
  2. On the Quest, open Quick Settings → Link from the Navigator
  3. Select your PC and LaunchFor Air Link (wireless), turn on Use Air Link and pair first
  4. Select SteamVR from the Link home screen to start it
  1. Install the Virtual Desktop app on your headset (sold separately: Quest via the Meta Horizon Store, PICO via the PICO Store)
  2. Install the Virtual Desktop Streamer on your PC, enter the username of your headset account (Meta or PICO) under ACCOUNTS and click Save
  3. Launch Virtual Desktop on the headset and connect to your PCOnce connected, your PC screen appears in the headset
  4. Select Launch SteamVR from the left menu
  1. Install Steam and SteamVR on your PC.
  2. Connect your PC and headset to the same network. A wired connection from the PC to the router is recommended.
  3. Install Steam Link from the store on a supported headset.
  4. Open Steam Link in the headset and follow the on-screen pairing instructions.

Supported devices and connection requirements (Steam)

Launch the Game

  1. Open the MRsecretVR_PCVR folder you placed
  2. Double-click MRsecretVR.exe
  3. The game starts and appears in your VR headset

Congratulations!

You're all set! Enjoy your time with her to the fullest!

02

Quest Setup

Setting Up the Quest Standalone Version

This method uses the Quest browser and Files app. A phone is also needed if you need to set up developer mode.
If it does not work, use B. SideQuest.

Prepare the APK File

  1. In the Quest browser, go to DLsite, log in and download the game
  2. Open the Files app, select the three-dot menu on the downloaded zip, then Extract

If extraction fails, try Option 2. The APK can't be installed while it's still zipped.

  1. Extract the downloaded game files on your PC
  2. Connect the Quest to your PC via USB
  3. In the Quest, select Allow to grant file access
  4. Copy MRsecretVR.apk from your PC to the Quest's Download folder

Install the APK

  1. Find MRsecretVR.apk in the Files app
  2. On the APK, select the three-dot menu → Open with → Package Installer
  3. Install → Done

If it won't install or launch, complete Enable Developer Mode and try again.

Launch the Game

  1. Press the Meta button to open the menu and select Library at the bottom center
  2. Select the three-line menu icon at the left edge of Library
  3. Select Unknown Sources
  4. Select MRsecretVR to launch it

The menu icon at the left edge is small and can be hard to hit. That's down to the Quest's own interface. Move the pointer slowly and press when the "Menu" label appears.

Note: Opening Unknown Sources works slightly differently depending on your Quest version. Unknown Sources doesn't appear unless Developer Mode is enabled. If it still doesn't appear after enabling it, restart the Quest.

Enable Developer Mode

  1. Register an organization on Meta Quest for DevelopersSee "How to register an organization" below
  2. Turn on Bluetooth on your phone and open the Meta Horizon app (formerly the Meta Quest app)
  3. From the three-line menu, select Devices
  4. Select your Quest (check that it shows "Connected")
  5. Headset settings → turn on Developer mode
  6. Restart the Quest
How to register an organization
  1. Go to Meta Quest for Developers and log in with your Meta Quest account
  2. Complete the Meta verification steps shown on screen
  3. Follow the on-screen instructions to register an organization

Install the ADB Driver

  1. Click Download on the Meta Quest Developer Center
  2. Check "I have read and agree to the terms of the license ." and click Download to save
  3. Unzip the file
  4. Right-click android_winusb.inf and select Install
  5. When "The operation completed successfully." appears, click OK

Install SideQuest

  1. On the SideQuest website, click Download for Windows under "SideQuest desktop app"
  2. Run the downloaded file to install

Connect the Quest to Your PC

  1. Connect the Quest to your PC with a USB cable
  2. In the Quest, at "Allow USB debugging?" select AllowTo skip this next time, check "Always allow from this computer"
  3. Select the bell icon at the bottom of the home menu: Notifications → USB detected
  4. At "Allow connected device to access files?" select Allow

Install the Game

  1. Open SideQuest and check that the Quest is detectedIf it shows No device connected, the Quest isn't connected. Check the connection to your PC
  2. Open Sideload at the top
  3. Drop MRsecretVR.apk into the box (or click it to choose the file)
  4. Done when History shows Completed

Launch the Game

  1. Press the Meta button to open the menu and select Library at the bottom center
  2. Select the three-line menu icon at the left edge of Library
  3. Select Unknown Sources
  4. Select MRsecretVR to launch it

The menu icon at the left edge is small and can be hard to hit. That's down to the Quest's own interface. Move the pointer slowly and press when the "Menu" label appears.

Note: Opening Unknown Sources works slightly differently depending on your Quest version. Unknown Sources doesn't appear unless Developer Mode is enabled. If it still doesn't appear after enabling it, restart the Quest.

Update

How to Update

Download the latest version from the store where you purchased the game. Updating from an older version works differently on PCVR and standalone Quest.

PCVR Version

Your save data carries over with this update.

  1. Extract the downloaded files
  2. Run the new version's MRsecretVR.exe
If you can't select anything in the start screen menu
  • Update the full version to ver1.2.0 or later. This update fixes controller input issues and launching from folder paths containing Japanese characters or spaces.
  • If the issue continues, see Troubleshooting.

Quest Standalone Version

Save data cannot be transferred when updating from the previously distributed store version to full ver1.2.0 for the first time.Progress, unlocked modes, collected outfits and hairstyles, and settings will be reset. You will need to start the game again.

  1. Get the new version's MRsecretVR.apk
  2. If moving from the old store release to ver1.2.0 for the first time, uninstall the old version after confirming that your save data will be reset
  3. Install the new APK using the standalone Quest installation guide

If you have already moved to this full ver1.2.0 release, you do not need to uninstall it to reinstall the same release.

Once updated, enjoy the new features and improved experience!
